# Mission 1 — Know your computer

## 1. Task / objective

Trace an everyday activity through input, processing, output and storage. Identify hardware, software and other computer-based systems.

## 2. Work completed

Created and read back a one-line plain-text note on the Mac. Used the note to map the four IPOS stages and classified eight components and apps.

### IPOS for creating and saving a note

| Stage | What happens | Component |
| --- | --- | --- |
| Input | The typed text and command enter the computer as keystrokes. | Keyboard |
| Processing | The shell interprets the command. The CPU runs it and memory holds the text and program state while it runs. | CPU and RAM |
| Output | Reading the saved note displays its line in the terminal window. | Display |
| Storage | The shell writes the line to a file. The note can be read again after the shell closes. | SSD and file system |

### Hardware and software

| Item | Classification | Software type | Purpose |
| --- | --- | --- | --- |
| Built-in keyboard | Hardware | — | Enters text and commands. |
| Display | Hardware | — | Shows text, images and windows. |
| Apple silicon processor | Hardware | — | Runs instructions. |
| SSD | Hardware | — | Stores files when the computer is turned off. |
| macOS | Software | Operating system | Manages memory, devices, files and processes. |
| Brave | Software | Application | Opens websites and web apps. |
| VS Code | Software | Application | Edits code and Markdown and works with Git. |
| Disk Utility | Software | Utility | Inspects and manages disks and volumes. |

### Computer systems in everyday life

| System | Main purpose | One input | One output |
| --- | --- | --- | --- |
| ATM | Lets a bank customer withdraw cash. | Amount entered on the keypad | Cash from the dispenser |
| Traffic signal controller | Controls which direction can move through a junction. | Timer event | Red, amber or green signal |
| Metro ticket machine | Sells tickets for selected routes. | Destination selected on the touchscreen | Printed ticket |

## 3. Commands / tools used

- `printf` wrote the sample sentence to a file using output redirection.
- `cat` retrieved the saved line from the file.

## 4. My understanding

A keystroke is input. The CPU and memory do the work needed to carry out the save. The text visible on the screen is output, and the copy on the SSD is what makes the note available later. The four roles are distinct even when the whole activity takes less than a second.
