## Topics explored

The missions cover input, processing, output and storage, Terminal file operations, macOS processes and permissions, program execution, number bases, text encoding, Git collaboration and how websites load.

## Run the number converter

From the repository root, use:

```bash
cd mission-05-numbers-data
python3 number_converter.py
```

Enter a decimal integer such as `25`. The program prints its binary and hexadecimal representations. This run prints `0b11001` and `0x19`.

## Learning summary

Creating a note shows how the shell, filesystem and persistent storage work together. Python represents the same integer in more than one base, and Git records changes so each stage can be reviewed separately. The network exercise distinguishes reaching a site from manually looking up a DNS record.

Each mission is documented, committed and pushed as a separate checkpoint.
