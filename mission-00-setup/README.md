# Mission 0 — Create a GitHub workspace

## 1. Task / objective

Set up a local Git project and a matching public GitHub repository named `digital-detective-8067`.

## 2. Work completed

Created the root project index, nine mission folders with starter READMEs, a starter file for the number converter and an optional evidence folder.

## 3. Commands / tools used

| Command or tool | Purpose |
| --- | --- |
| `python3 --version` | Verified Python 3.14.7 was available. |
| `git --version` | Verified Git 2.56.0 was available. |
| `mkdir`, `touch` | Created the project folders and starter files. |
| `git init -b main` | Started version history on the `main` branch. |
| `git add`, `git status`, `git commit` | Prepared, inspected and saved the setup snapshot. |
| GitHub and `git push` | Published the setup checkpoint to the matching remote repository. |

## 4. My understanding

A repository holds a project's files and the history of changes made to them. Keeping a README inside each mission makes its explanation and evidence easy to find without searching through all the other topics.

## 5. Difficulties faced

The optional evidence folder was empty, and Git tracks files inside folders.

## 6. How I resolved them

Added an empty `.gitkeep` file so the evidence folder would appear in the initial checkout.

The [root index](../README.md), nine mission READMEs, the [number converter starter](../mission-05-numbers-data/number_converter.py), and the [evidence folder](../evidence/) make up the initial structure.
